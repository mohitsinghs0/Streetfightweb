# 3D Fighter Models Directory

Place your custom 3D character models here:

- `public/models/fighter.glb` (Player 1)
- `public/models/opponent.glb` (Player 2 / Bot)

### Recommended Format:
- **Format**: `.glb` (glTF 2.0 Binary)
- **Rigging**: Standard Humanoid Rig (Mixamo compatible skeleton: `Hips`, `Spine`, `Head`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg`)
- **Embedded Animations** (Optional or via Mixamo):
  - `Idle`
  - `Jab` / `Punch`
  - `Cross`
  - `Kick`
  - `Block`
  - `Hit` / `Reaction`
